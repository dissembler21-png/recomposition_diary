# Дневник рекомпозиции

Личное приложение для тренировок, подъёмов по лестнице, питания и замеров.

- `src/diary.html` — исходник. Этот же файл опубликован как страница на claude.ai (облачная база и подсчёт калорий).
- `python3 build.py` собирает офлайн-версию (PWA) в `docs/`, которую раздаёт GitHub Pages.
- Записи в репозиторий не попадают: офлайн-версия хранит их на телефоне, перенос в основной Дневник идёт через «Ещё → Скопировать / Вставить».
